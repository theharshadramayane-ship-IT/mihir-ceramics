# Mihir Ceramics Website

A single-page website UI prototype for Mihir Ceramics, featuring brand imagery and a background video.

## Project Overview

This project is the starting point for a future website for Mihir Ceramics. The current version contains an HTML-based user interface and supporting media assets.

## Current Features

- Single-page website UI
- Mihir Ceramics logo
- Background image and video assets
- Foundation for future website improvements

## Technologies

- HTML
- CSS and JavaScript, where used in the current page

## Project Files

- `hr.html` — main website page
- `Mihir-LOGO.jpeg` — logo asset
- `Mihir background.png` — background image
- `background vidio.mp4` — background video

## How to View

Download or clone this repository, keep the HTML file and media assets in the same directory, and open `hr.html` in a web browser.
